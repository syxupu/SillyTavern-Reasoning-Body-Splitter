# 思考正文分离器（Reasoning Body Splitter）

适用于 SillyTavern 的前端扩展。在最新一条 AI 回复生成后，提供 **分离思考** 和 **✓** 两个按钮，让你先检查回复，再决定何时定稿。已在 SillyTavern 1.16.0 上测试。

## 开发背景

使用 DeepSeek API 对话时，模型偶尔不能按预期区分思考与正文：本该显示在正文中的剧情被写到思考末尾，聊天界面的正文因此可能是空白的。本插件为这种情况提供手动分离与定稿操作，尽量把已有剧情放回正文，而不重新创作内容。

## 安装

在酒馆中打开 **扩展 → 安装扩展**，粘贴此仓库的 Git 地址：

```text
https://github.com/syxupu/SillyTavern-Reasoning-Body-Splitter.git
```

安装后刷新酒馆页面。按钮会出现在聊天输入栏上方的快捷回复栏中；如果没有快捷回复栏，则显示在输入框上方。

也可以下载仓库文件，把整个文件夹放入 `data/<用户>/extensions/`，然后刷新页面。确保 `manifest.json` 位于该文件夹根目录。

## 使用

1. 收到 AI 回复后，可以直接按 **✓** 定稿；不需要每次都先点“分离思考”。
2. 如果剧情正文落在思考内容里，点 **分离思考** 查看提取预览，再按 **✓** 保存。插件只依据 `</thinking>`、`</think>`、`</analysis>` 或明确的“正文：”边界搬移已有文字，不调用聊天 API，也不创作或改写剧情。
3. 不点 **✓**，直接发送下一条消息，也相当于先自动点 **✓**：有分离预览时采用预览，否则采用当前原回复，然后继续发送。若正文仍为空，插件会拦截发送，要求先修复或重抽。
4. 若其他扩展在你点击按钮前改动了原始正文或思考字段，本扩展会以点击时的最新内容为准；过期的分离预览不会覆盖新内容。

插件只处理当前聊天的最新 AI 回复及当前 swipe。没有明确边界时不会猜测正文；正文为空且无法可靠提取剧情时，不能定稿，请重抽或手工补正文。

> 小白盒提示：独立安装本扩展不包含小白盒循环任务及故事总结的桥接修改，未适配的小白盒可能在定稿前读取初稿。
